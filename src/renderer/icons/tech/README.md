# Tech icons

Vendored from https://github.com/catppuccin/vscode-icons at commit
b6915da9f6889b683a110aa747de96c2820a537d (MIT license, see LICENSE).

Two flavors: `mocha/` (dark theme) and `latte/` (light theme). Ids map to
files by name: `<flavor>/<id>.svg`, where the ids are listed in
`src/tech-ids.js`. Where Catppuccin has no dedicated icon, an id reuses the
closest Catppuccin icon (for example its language or database icon). The
files are unmodified copies.
