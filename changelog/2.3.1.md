# Spaci 2.3.1

## One row per project, worktrees included

AI coding tools and git worktrees leave many copies of the same repository behind. Spaci now groups every package and every linked worktree under its repository, so a project with 40 worktrees is one row, not hundreds. Each worktree shows its branch, whether it has changes, whether it is merged or pushed, when it was last active, its size, and which tool likely created it.

Worktrees that are merged or pushed, have no changes and are not locked can be removed, one at a time or together, after a confirm that lists each one. Spaci uses `git worktree remove` without force, keeps the branch, and records how to bring each one back. A worktree with edits, hidden edits, commits found nowhere else, local data such as `.env` files, or recent activity is shown with the reason and never offered.

## Local AI models

Ollama, LM Studio, Hugging Face and other local AI tools are listed with each model's real size on disk and whether it is loaded right now. A model is deleted on its own, through the tool's own command where it has one, never while it is loaded, and comes back with the command Spaci shows.

## Developer tools

Unused simulator runtimes, Android system images and emulators, old Node, Python and Rust versions, old IDE caches, superseded editor extensions and browser test downloads are listed in System Cleaner. Versions your projects pin, your defaults and anything running are protected.
