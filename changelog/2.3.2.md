# Spaci 2.3.2

## Tools clean their own caches

Homebrew, uv, pnpm, npm, Yarn, Go, Gradle and other tools now clean their caches with their own commands, such as `brew cleanup` or `uv cache clean`, instead of Spaci deleting the folder. Each row shows the exact command it runs, and a preview shows what it would remove first. History records the command and its result.

Spaci only runs commands from a fixed list, with fixed arguments. A tool that is busy (an install running, a lock held, a Gradle daemon working) is refused straight away instead of waited on, and Spaci checks again right before it runs. A command that is not safe to stop is never cancelled halfway. If one does end early, the row says so and offers to finish the clean.

`brew cleanup` runs with Homebrew's autoremove switched off, and Spaci checks Homebrew's dry run first, so it never uninstalls formulae Homebrew thinks are unneeded. Because `brew cleanup` also removes old installed versions, Homebrew is now in Review, not Safe.

## Fixes

- The tree icon no longer appears anywhere in the app.
- On Linux, folders inside `/usr` and `/usr/local` that already belong to a category (such as an Android SDK) are no longer counted twice.
- Simulator notes name devices in a stable order.
