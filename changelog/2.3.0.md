# Spaci 2.3

## Clean all developer files in one go

Build output and package caches rebuild on the next install or build, so Spaci now groups them. **Clean all developer files** on the Dashboard and in Projects removes every one Spaci has verified with git, such as `node_modules`, `.next`, `dist`, `target` and the npm, pnpm, cargo and gradle caches, after a single confirm that lists what goes and how each comes back.

Everything else is grouped by risk:

- **Safe**: cleaned together with one confirm.
- **Review**: app and browser caches, Docker images, virtual environments and the Maven repository, each confirmed by category.
- **Permanent**: the Trash, archives, logs, AI tool history and Docker volumes, never in bulk, each confirmed on its own.

## Auto-clean, if you want it

Off unless you turn it on in Settings. It only touches safe build output of projects you have not changed for 30 days and package caches over 1 GB, only on power and while you are away, never while the tool that owns them is running, and never in cloud-synced folders or on other disks. The first run is a preview you approve in History. Everything it moves stays in a holding folder for 24 hours, with **Undo** in History, before it is removed for good.

## Storage explains your whole disk

The Storage screen now accounts for the space macOS, Windows and Linux use themselves: system volumes, swap, snapshots, simulator runtimes, Homebrew, package manager caches, virtual disks and more. Each item says whether it is safe, needs a review, is permanent, or is managed by your system, in which case Spaci shows the system's own cleanup command. What Spaci is not allowed to read is named, with a shortcut to grant access.

## Also new

- **What's new and notices**: this screen, and a bell for news about Spaci. Switch news off in Settings.
- **Logos** for AI tools, Docker, browsers, languages and frameworks across the app.
- **Docker volumes** grouped by project, each removable on its own after a confirm, and a Restart button when Docker stops responding.
- **Faster and smoother**: scans run in the background without freezing the window.
- **Keyboard and screen reader support**, stronger contrast, and reduced motion when your system asks for it.
